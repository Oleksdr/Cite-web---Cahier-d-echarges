# Documentation : financement.html

## Description
Page présentant les solutions de financement avec une grille de cartes et des statistiques.

## Structure

### Section Hero
- Image de fond avec texte superposé
- Titre "Financement" et description
- Même style que equipements.html

### Section Solutions
- Grille de 6 cartes (3 colonnes sur desktop)
- Chaque carte a une icône emoji, un titre et une description
- Icônes : 💰 📊 👥 ⚙️ 💻 ♻️

### Section Stats
- Deux statistiques affichées
- Fond gris clair pour se démarquer
- Texte centré

## Pourquoi cette structure

### Grille de solutions
- Présente 6 solutions de manière équilibrée
- Cartes visuellement attractives avec icônes
- Facile à scanner et lire

### Section stats
- Met en avant les chiffres clés
- Design simple et efficace

## Balises HTML

### `<main>`
- Contenu principal de la page
- Permet au footer de rester en bas

### `<section>`
- Structure le contenu
- Améliore le SEO

## Classes importantes
- `.hero` : Section hero
- `.solutions-grid` : Grille de solutions
- `.solution-card` : Carte individuelle
- `.stats` : Section statistiques
- `.stat-item` : Item de statistique

## Emojis
- Utilisés comme icônes pour rester simple
- Pas besoin de bibliothèque d'icônes
- Compatible partout
